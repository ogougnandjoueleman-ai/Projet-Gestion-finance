# Gestion Financière - Groupe 4

Application de gestion financière avec interface graphique Windows (WinAPI).

## Fonctionnalités
- Dépôt de fonds
- Retrait de fonds
- Historique des transactions
- Sauvegarde automatique du solde

## Compilation avec Code::Blocks

### Prérequis
- Code::Blocks installé avec MinGW
- Windows uniquement

### Étapes
1. Ouvrir le fichier `gestion_financiere.cbp` dans Code::Blocks
2. Aller dans **Project** → **Build options**
3. Cliquer sur l'onglet **Linker settings**
4. Dans **Link libraries**, cliquer sur **Add** et taper `gdi32`
5. Cliquer **OK** et compiler avec **F9**
